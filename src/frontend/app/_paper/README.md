# Retired: technical report on the v2 layouter

This folder holds the draft technical report on the staged constructive
layouter (v2) and its benchmark data. It was never finished and never made public to the
website. If you find it in the repo, please consider it a started paper not finished work.

v2 has been superseded by the v5 annealed layouter (autoLayout5.ts), which
outperforms it on every benchmark in this report. The files are kept as a
record and as a starting point should the report ever be finished or a new
one written about v5. The numbers in data.ts describe v2 as of layouter
2.1.3 and are not current.
